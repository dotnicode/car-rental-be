# Autenticacion y gestion de usuarios

- [US-01] As a client, I want to be able to sign up, recover my password and logout from my account
- [US-02] As a client, I want an user account so that I can request rentals
- [US-03] As a developer, I need to set up the user module for the clients
- [US-04] As a developer, I need to set up user roles -admin, user- in order to provide two separate user interfaces
- [US-05] As a developer, I want that non admin users are redirected from admin pages
- [US-06] As a client I want to update my user details
